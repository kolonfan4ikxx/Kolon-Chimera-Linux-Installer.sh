# Kolon Chimera Linux Installer

Простой интерактивный установщик Chimera Linux от Kolon.

Установщик позволяет настроить:

- имя компьютера;
- имя пользователя;
- пароль пользователя;
- root-пароль;
- репозиторий;
- ядро;
- загрузчик;
- графическую среду;
- разметку диска и другие параметры.

> **ВНИМАНИЕ:** установка операционной системы может удалить данные с выбранного диска. Перед установкой сделайте резервную копию важных файлов и внимательно проверяйте выбранный диск.

## 1. Загрузите Chimera Linux Live

Загрузитесь с установочного Live-носителя Chimera Linux.

После загрузки откройте терминал и перейдите в root:

```sh
su -
```

Проверьте подключение к интернету:

```sh
ping -c 3 repo.chimera-linux.org
```

## 2. Скачайте установщик

Скачайте актуальную версию `install.sh` из GitHub:

```sh
wget https://raw.githubusercontent.com/kolonfan4ikxx/Kolon-Chimera-Linux-Installer.sh/main/install.sh
```

## 3. Запустите установщик

Сделайте файл исполняемым:

```sh
chmod +x install.sh
```

Запустите:

```sh
./install.sh
```

Установщик начнёт пошаговую настройку системы.

## 4. Выберите диск

Сначала установщик покажет доступные диски.

Например:

```text
NAME   SIZE TYPE
sda    477G disk
sdb    931G disk
```

Введите нужный диск:

```text
/dev/sda
```

**Обязательно убедитесь, что выбрали правильный диск.**

## 5. Разметка диска

Установщик предложит вариант разметки.

Если выбрана автоматическая разметка, установщик подготовит необходимые разделы.

Если у вас уже есть разделы, можно выбрать существующие разделы и указать их вручную.

## 6. Имя компьютера

Установщик спросит:

```text
PC name:
```

Например:

```text
kolon-pc
```

Это будет hostname установленной системы.

## 7. Создание пользователя

Введите имя пользователя:

```text
Username:
```

Например:

```text
kolon
```

Затем установщик попросит пароль пользователя и повтор пароля.

Пароль при вводе не отображается — это нормально.

## 8. Root-пароль

Далее задайте пароль root:

```text
Root password:
```

И повторите его.

## 9. Репозиторий

Установщик предложит выбрать репозиторий.

Для обычной установки можно использовать официальный репозиторий Chimera Linux.

Также предусмотрена возможность указать собственный URL репозитория.

## 10. Выберите ядро

Установщик предложит доступные варианты ядра, например:

```text
1) linux-lts
2) linux-stable
```

Выберите нужный вариант.

Если не знаете, что выбрать, используйте рекомендуемый вариант, который предлагает установщик.

## 11. Выберите загрузчик

В зависимости от режима загрузки компьютера установщик предложит подходящие варианты загрузчика.

Обычно для UEFI можно использовать GRUB.

Если используется BIOS/Legacy, выбирайте вариант, соответствующий BIOS.

## 12. Выберите графическую среду

Установщик позволяет выбрать окружение рабочего стола.

Например:

```text
1) None
2) GNOME
3) KDE Plasma
4) XFCE
5) Sway
```

Можно выбрать `None`, если вы хотите получить минимальную систему и самостоятельно установить нужное окружение позже.

## 13. Проверьте настройки

Перед началом установки установщик покажет итоговую конфигурацию.

Например:

```text
Installation summary

Disk:        /dev/sda
EFI:         /dev/sda1
Root:        /dev/sda2

PC name:     kolon-pc
Username:    kolon
Repository:  official
Kernel:      linux-stable
Bootloader:  GRUB
Desktop:     KDE Plasma
```

**Внимательно проверьте эту информацию.**

Если всё правильно, подтвердите установку.

## 14. Установка

После подтверждения установщик автоматически:

1. подготовит файловую систему;
2. выполнит bootstrap Chimera Linux;
3. настроит репозитории;
4. установит выбранное ядро;
5. установит базовые пакеты;
6. создаст пользователя;
7. настроит hostname;
8. установит выбранный загрузчик;
9. установит выбранную графическую среду.

Дождитесь сообщения об успешном завершении.

## 15. Перезагрузка

После окончания установки перезагрузите компьютер:

```sh
reboot
```

Перед загрузкой установленной системы извлеките Live-носитель.

После перезагрузки должна запуститься установленная Chimera Linux.

# Быстрая установка

Если вы уже находитесь в Chimera Linux Live и понимаете, какой диск будете использовать:

```sh
su -
wget https://raw.githubusercontent.com/kolonfan4ikxx/Kolon-Chimera-Linux-Installer.sh/main/install.sh
chmod +x install.sh
./install.sh
```

Дальше просто следуйте инструкциям установщика.

# Безопасность

Перед запуском установщика убедитесь, что вы скачали файл из официального репозитория проекта:

[Kolon Chimera Linux Installer на GitHub](https://github.com/kolonfan4ikxx/Kolon-Chimera-Linux-Installer.sh?utm_source=chatgpt.com)

Не запускайте установщики, скачанные из неизвестных источников.

# После установки

После первого запуска Chimera Linux можно устанавливать программы через `apk`:

```sh
doas apk update
doas apk add git
```

Поиск пакетов:

```sh
doas apk search <название>
```

Удаление:

```sh
doas apk del <название>
```

Обновление системы:

```sh
doas apk upgrade
```
